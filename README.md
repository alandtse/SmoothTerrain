# SmoothTerrain

An SKSE plugin that subdivides Skyrim's landscape meshes at the engine level for smoother terrain.

Supports Skyrim SE, AE, and VR with a single DLL.

## Contributing

Contributors are welcome. You can build the project by running the `buildRelease.ps1` powershell
script from a visual studio dev powershell prompt

AI usage is allowed and was used during the development of this plugin, however, all code merged
must be approved manually and understood/verified fully by its author and this project's
maintainers.
